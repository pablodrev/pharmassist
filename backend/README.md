# 💊 Pharmacovigilance Analysis MVP

Система анализа сообщений о нежелательных реакциях на лекарственные препараты.

## Возможности

- **Структурированное извлечение** данных кейса (пациент, репортёр, НР, препарат)
- **Оценка клинической значимости** по спискам EMA IME (семантический поиск по MedDRA)
- **Алгоритм Наранжо** — LLM отвечает на 10 вопросов, алгоритм считает баллы детерминированно
- **Оценка предвиденности** — RAG по ИМП препарата (загружается пользователем)
- **Валидация обязательных полей** — предупреждение о недостающих данных
- **Полностью локально** — без отправки данных в облако

## 🚀 Установка и запуск

### 1. Установить Ollama

```bash
# macOS / Linux
curl -fsSL https://ollama.com/install.sh | sh

# Windows — скачать с https://ollama.com/download
```

### 2. Запустить Ollama и загрузить модель

```bash
# Запустить сервер (оставить работающим)
ollama serve

# В новом терминале — загрузить модель
ollama pull mistral

# Опционально — лёгкая альтернатива
ollama pull phi3:mini
```

### 3. Создать виртуальное окружение и установить зависимости

```bash
cd pharmacovigilance

python -m venv venv

# macOS / Linux
source venv/bin/activate

# Windows
venv\Scripts\activate

pip install -r requirements.txt
```

> ⚠️ При первом запуске `sentence-transformers` скачает модель (~120 MB).
> Это происходит один раз и кэшируется локально.

### 4. Запустить приложение

```bash
streamlit run app/main.py
```

Откроется браузер на `http://localhost:8501`

## 📋 Использование

### Ввод кейса
1. Вставьте текст сообщения о НР в текстовое поле **или** загрузите TXT файл
2. Используйте кнопку **«Примеры кейсов»** для тестирования

### Загрузка ИМП
- В левой панели загрузите PDF инструкции по медицинскому применению
- Система автоматически проиндексирует её для RAG

### Загрузка EMA IME списка
- Загрузите актуальный CSV файл с колонками: `MedDRA`, `PT Name`, `SOC Name`
- Актуальный список: https://www.ema.europa.eu/en/human-regulatory-overview/post-authorisation/pharmacovigilance/eudravigilance/important-medical-event-terms

### Анализ
- Нажмите **«🔍 Анализ»**
- Дождитесь результатов (30–90 секунд в зависимости от модели и железа)

## ⚙️ Архитектурные решения

| Компонент | Решение | Причина |
|-----------|---------|---------|
| LLM | Ollama (локально) | Конфиденциальность медданных |
| Embeddings | `paraphrase-multilingual-MiniLM-L12-v2` | Поддержка русского, лёгкая (~120MB) |
| Vector DB | FAISS (in-memory) | Без внешних зависимостей |
| Валидация LLM output | Pydantic v2 | Типобезопасность, retry при ошибке |
| Наранжо скоринг | Детерминированный алгоритм | LLM только отвечает на вопросы, баллы считаются кодом |

## 🔧 Troubleshooting

**Ollama не запускается:**
```bash
# Проверить статус
curl http://localhost:11434/api/tags
```

**Ошибка памяти при загрузке модели:**
- Используйте `phi3:mini` вместо `mistral`
- Закройте другие приложения

**Медленная работа:**
- `phi3:mini` работает быстрее на слабом железе
- Первый запрос всегда медленнее (загрузка модели в RAM)
